# Hexfront

A classic hex-and-counter WWII wargame for the browser: play the computer, share one screen, or play by email.

**Fronts:** Border War (base game) · Road to the Rhine (Europe 1944) · Gazala Line (North Africa 1942)

## Play
Open `index.html`, or visit this repository's GitHub Pages site. On a phone, use **Add to Home Screen**.

## Features
- Hard computer opponent that plays fair under fog of war
- Optional fog of war, entrenchment orders, artillery bombardment
- Phone layout: map toolbar, unit info and orders popups, slide-up Battle / Objectives / Forces / Log / Charts panels
- Play by email with compressed turn codes (dice are stored in the code)

## Files
| Path | What it is |
|---|---|
| `index.html` | The whole game |
| `manifest.webmanifest` | App name, colours and icons for Add to Home Screen |
| `icons/` | App icon and header logo |
| `images/` | Terrain textures, named `{set}_{terrain}_{variant}.jpg` |
